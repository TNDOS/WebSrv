TNX：为什么不用 PE Why not PE

在 UEFI 底下，PE 是免费的 —— LoadImage 是固件替我们写的加载器。 所以 TNX 的价值不是「比 PE 简单」，而是：当我们不能再调 LoadImage 的时候，我们还能加载程序。
方案成本
继续用固件 LoadImage0，代价是永远离不开 UEFI
自己写 PE 加载器约 800 行，全是边界情况
TNX + tnxpack + 加载器规格 + 约 300 行打包器 + 约 250 行加载器

自己构建 Build it yourself

需要：Windows + PowerShell、LLVM（clang 与 ld.lld）、QEMU 与 OVMF、以及全部四个仓库。

setx TNDDOS_LLVM_BIN "D:\LLVM\bin"
setx TNDDOS_QEMU     "D:\qemu\qemu-system-x86_64.exe"
setx TNDDOS_TOOLKIT  "D:\TNDOS-ToolsKit"
setx TNDDOS_SDK      "D:\TNDOS-SDK"
setx TNDDOS_SYSAPP   "D:\TNDOS-SysAPP"

cd TNDOS-SysCore
.\tools\build-run.ps1

build-run.ps1 一条命令做完：编译 -> 组装 EFI System Partition -> 生成真实 FAT16 磁盘映像 -> 无头 QEMU/OVMF 启动 -> 打印串口日志。 加 -Seconds N 控制启动时长，-NoRun 只编译。
